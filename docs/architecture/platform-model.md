# Platform Model

## Platform infrastructure
Identity, publishing, domains, media, email transport, analytics ingestion, payment rails, subscriptions and AI infrastructure.

## Business capabilities
Portfolio, testimonials, enquiry, lead, availability, booking, deposit, service/package, download, location and newsletter.

## Vertical schema examples

### Tattoo
Tattoo styles, flash, books open/closed, placement, approximate size, reference images and tattoo-specific policies.

### Events
Event date, venue, guest count, service area, packages and qualification fields.

### Speakers
Topics, speaking reel, audience size, travel, media kit and keynote enquiry.

## Generalization rule
**Product-specific first. Shared only when proven generic.**

Do not create abstractions solely because a future vertical might need them.
