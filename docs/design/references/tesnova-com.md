# Design Reference — Tesnova.com

**Reference:** https://www.tesnova.com/  
**Status:** Preserve permanently as Tessnova design research  
**Recorded:** 2026-10-06

## Why this reference is preserved

The Founder identified Tesnova.com as an unusually strong example of an exciting, attractive modern web experience.

The reference is especially notable for:

- mouse / pointer effects;
- hover interactions;
- transition choreography;
- scroll and entrance animations;
- color treatment;
- background composition;
- interactive component behavior;
- motion-rich section transitions;
- visual depth;
- typography and hierarchy;
- modern UI composition;
- overall sense of energy and polish.

The live site also presents a strong structure across:
- hero;
- work / portfolio;
- services;
- recent projects;
- pricing;
- company story;
- testimonials;
- agency/services sections;
- lead-generation contact form.

## Design intent for Tessnova

Do **not** copy Tesnova.com's code, assets, imagery, copy, layouts or trademark identity.

Instead, use it as a reference for **interaction principles and quality bar**.

Questions to revisit during M3 Product Design:

1. How can Tessnova create delight through pointer and hover behavior without harming usability?
2. Which transitions make navigation feel continuous rather than decorative?
3. How can background changes create section rhythm and visual depth?
4. Which component-level micro-interactions reinforce affordance?
5. What motion timing/easing creates premium polish?
6. Which effects remain performant on mid-range mobile devices?
7. What is the `prefers-reduced-motion` fallback?
8. Which interactions belong to the Tessnova product dashboard versus customer storefront themes?
9. How do we preserve accessibility, focus states and keyboard behavior?
10. How can we create a recognizably Tessnova motion language rather than imitate this reference?

## Tessnova principle

**Borrow the standard of craft, not the visual identity.**

The desired outcome is for Tessnova to feel equally intentional, exciting and polished while remaining unmistakably its own product.
