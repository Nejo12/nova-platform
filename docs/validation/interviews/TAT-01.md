# TAT-01 — Fine-line tattoo artist, Berlin

**Status:** Interviewed  
**Evidence quality:** Strong  
**Source:** Founder-collected response

## Business context

Fine-line tattoo artist in Berlin. Books have been closed since July. Instagram remains a discovery and enquiry channel even while books are closed.

## Current workflow

Returning client example:

Instagram discovery (historical)
→ email with references + placement + size + style + rough month
→ quote (€380)
→ €100 PayPal deposit
→ Google Calendar date

## Repeated client questions

- minimum price
- whether books are open
- how far ahead bookings run
- cover-up suitability
- whether deposit is deducted from final total

## Strong pain

### Unqualified DMs
A weak DM can take five messages before discovering the request is unsuitable.

### Books state is unreliable
Stories expire, screenshots circulate later, saved DMs are used as an informal waitlist and get lost.

### Flash can be double-sold
Current process is Instagram comment → DM → PayPal → manually mark post claimed.

Two customers have paid for the same flash sheet because the claimed state was updated too late.

## Required request fields

- placement
- size in centimetres
- black or colour
- two references
- rough month
- budget optional

No size → no quote.

## Deposits / policies

- custom deposit: €80
- flash deposit: €50
- credited to final price
- non-refundable inside 48 hours of appointment
- cancellation text pasted manually from Notes
- PayPal payment is not tied to the booking/date

## Product reaction

Would replace current bio link if clients could see:
- work
- minimum price
- books status

Would **not** switch merely for a prettier Linktree.

Would reject:
- generic/shared-looking artist pages
- clients paying “the platform” instead of directly to the artist

## Pricing evidence

- €9/month: negligible decision
- €19/month: yes if flash cannot be double-sold
- €39/month: requires integrated deposit collection
- above €39: should also replace more of PayPal/calendar workflow

## Jobs-to-be-done

1. Show whether books are open without answering DMs.
2. Qualify tattoo requests before the artist spends time replying.
3. Reserve scarce flash safely so it cannot be double-sold.
4. Tie a deposit to the specific request/design.

## Candidate product implications

- Books status is not a calendar.
- Flash requires real reservation state and anti-double-booking constraints.
- Custom tattoo request is a separate lead flow.
- Artist should remain merchant-facing; payment model must not feel like Tessnova owns the booking.
