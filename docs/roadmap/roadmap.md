# Tessnova Roadmap

## M0 — Foundation
Brand, repository, governance, Figma workspace and validation readiness.

## M1 — Market Validation
Validate Tattoo, Events and Speakers. Select one launch vertical using evidence.

## M2 — Product Definition
Lock V1 scope, jobs-to-be-done, domain model, success metrics and non-goals.

## M3 — Product Design
Low-fidelity flows, Claude Design exploration, canonical Figma designs and tested prototype.

## M4 — Technical Architecture
Application architecture, data model, security boundaries, Nova UI consumption and deployment model.

## M5 — MVP Alpha
Implement the selected vertical.

## M6 — Private Beta
Real professionals use Tessnova with hands-on support.

## M7 — Paid Beta
First paying customers and retention/conversion evidence.
